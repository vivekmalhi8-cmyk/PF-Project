# Programming Fundamentals Project

A small C program created as a Programming Fundamentals project starter. The current program prints a short greeting to the console and provides a minimal example of a C program's entry point.

## Source

- `PF Project` — C source code (the filename has no extension)

## Requirements

- GCC, Clang, or another C compiler

## Build and run

Using GCC from the repository root:

```bash
gcc "PF Project" -o pf-project
./pf-project
```

On Windows, run `pf-project.exe` after compiling. The repository currently contains a minimal example; add project details and features here as the work grows.

## Purpose

This repository is for learning and coursework. It has no external dependencies.
